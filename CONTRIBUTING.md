# Contributing

Этот репозиторий — **публичный feed обновлений**: установщики (Releases), документация и Discussions. **Исходный код приложения сюда не принимается.**

## Куда писать

| Тема | Куда |
|------|------|
| Баг | [Discussions → General](https://github.com/dorimeryt-alt/CoronerChat/discussions/new?category=general) (форма «Сообщить о баге») |
| Идея | [Discussions → Ideas](https://github.com/dorimeryt-alt/CoronerChat/discussions/new?category=ideas) |
| Вопрос / помощь | [Discussions → Q&A](https://github.com/dorimeryt-alt/CoronerChat/discussions/new?category=q-a) |
| Уязвимость | Только в Telegram [@coroner_of_autopsy](https://t.me/coroner_of_autopsy) — см. [SECURITY.md](SECURITY.md) |

Не открывайте Issue с багом, если можно Discussion: Issues здесь почти не используются.

## Баг-репорт

Нужны: версия (например `2.7.13`), площадка, шаги, ожидание/факт, фрагмент `runtime.log`.

Лог (обычный Setup):

```
%LOCALAPPDATA%\Programs\CoronerChat\CoronerChat-data\runtime.log
```

Подробнее: [Discussions #2](https://github.com/dorimeryt-alt/CoronerChat/discussions/2).

## Документация

Правки текстов сайта/`docs/` и wiki-зеркала — через PR в `main` (описательные изменения). Крупные продуктовые решения автор принимает сам.

## Сборка / код

Приватны. Вопросы по API площадок и поведению продукта — в Discussions или Telegram.
