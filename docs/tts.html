Voice queue

Озвучка сообщений

Последовательная очередь Chat TTS: системный голос Windows, облачные API и пять локальных движков с prefetch моделей в CoronerChat-data.

В Latest 2.7.12 доступны system + cloud. Локальные Piper / Silero / RHVoice / Supertonic / XTTS-v2 — в линии сборки (см. Unreleased в changelog); документация и ссылки на upstream уже здесь.

Where

Где включить

Эфир → Озвучка сообщений (Chat TTS): провайдер, голос, шаблон, фильтры платформ/ролей, Pause / Skip / Clear.

  • Очередь не блокирует чат
  • Fallback на system при ошибке локального синтеза
  • Ключи cloud API — только ваши

Local engines

Локальные движки

Один Python sidecar на loopback; модели и venv только в CoronerChat-data/tts-cache и tts-runtime (вне asar). Нужен системный Python 3.10+.

Piper

Лёгкий ONNX TTS. Prefetch: голоса ru + en (medium). Лицензия текущей линии — GPL (OHF-Voice/piper1-gpl).

Silero

Neural TTS (torch.hub). Prefetch: v5_ru + EN.

RHVoice

Локальный CLI/движок. Нужна системная установка RHVoice; prefetch проверяет голоса RU/EN (например Aleksandr).

Supertonic

Тяжёлый пакет — скачивание при первом выборе движка (1+ GB), с прогрессом в UI. На CPU может быть медленно.

Coqui XTTS-v2

Тяжёлый пакет через Coqui TTS; on-demand prefetch. В v1 — дефолтный/один reference из кэша, без произвольного клонирования в UI.

Лёгкий пакет (Piper + Silero + проверка RHVoice) — при первом включении локального TTS. Тяжёлый (Supertonic / XTTS) — кнопкой «Скачать тяжёлый пакет» или при первом выборе движка. Повторный старт сверяет manifest.json + sha256, без лишней перекачки.

DonationAlerts

Можно ли вытащить голос из DonationAlerts?

Нет — встроенный TTS алертов DA не отдаёт движок и URL синтеза через публичный OAuth API.

  • В кабинете DA настраиваются пол, скорость, порог суммы — синтез играет внутри их alert-виджета (справка DA).
  • API donations даёт текст (message) и тип text / audio. Для audio это голосовое сообщение донатера, а не ссылка на движок TTS алертов.
  • sound_url есть у custom alerts, которые вы сами отправляете — это ваш файл, не «голос DA».

Практичный путь в CoronerChat: текст доната → своя очередь Chat TTS (system / cloud / локальные движки выше).

Privacy

Приватность и стоимость

System и локальные движки держат синтез на машине (после prefetch моделей). Cloud API получают подготовленный текст и тарифицируются у провайдера. Ключи CoronerChat не поставляет.
