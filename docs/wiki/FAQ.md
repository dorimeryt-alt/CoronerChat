# FAQ

## Где скачать?

[Releases → Latest](https://github.com/dorimeryt-alt/CoronerChat/releases/latest) — **v2.7.12**.

## Почему раньше предлагали 2.35.x?

В архиве есть старые номера. С **2.7.5** берётся GitHub Latest.

## Какие движки озвучки?

System, cloud (OpenAI / ElevenLabs / Google / Azure) и локальные Piper, Silero, RHVoice, Supertonic, XTTS-v2.

Полный список со ссылками: https://dorimeryt-alt.github.io/CoronerChat/tts.html

## Можно ли вытащить голос из DonationAlerts?

Нет. Публичный API DA отдаёт текст доната (`message`) и тип `text`/`audio` (голосовое сообщение донатера), но **не** URL и не имя движка встроенного TTS алертов. Озвучивайте текст своей очередью Chat TTS в CoronerChat.

## Пропали настройки?
