# Discussions

Сообщество CoronerChat: баги, идеи, вопросы.

Открыть: https://github.com/dorimeryt-alt/CoronerChat/discussions

## Категории

| Категория (сейчас) | Для чего | Форма при создании |
|--------------------|----------|--------------------|
| **General** | Баги | Сообщить о баге |
| **Ideas** | Предложения / фичи | Предложение / фича |
| **Q&A** | Вопросы и помощь | Вопрос / помощь |
| **Show and tell** | Сетапы, скрины | Сетап / Show and tell |
| **Announcements** | Новости от автора | Объявление |
| **Polls** | Опросы | — |

Лейблы: `баг`, `предложение`, `помощь`, `tts`, `obs`, `twitch`, `vk`, `kick`, `youtube`, `rutube`, `tiktok`.

## Переименование категорий (для автора)

GitHub API не даёт создать/переименовать категории — только через UI:

1. https://github.com/dorimeryt-alt/CoronerChat/discussions  
2. Слева у **Categories** → шестерёнка  
3. Рекомендуемые имена:

| Было | Станет |
|------|--------|
| Announcements | Объявления |
| General | Баги |
| Ideas | Предложения |
| Q&A | Вопросы |
| Polls | Опросы |
| Show and tell | Сетапы |

Slug категорий (`general`, `ideas`, `q-a` …) лучше **не менять** — на них завязаны формы в `.github/DISCUSSION_TEMPLATE/`.
