# Code of Conduct

## Our pledge

CoronerChat Discussions and related community spaces are for streamers, mods and users of the app. Be respectful.

## Expected

- Clear bug reports and questions (version, steps, logs without secrets)
- Constructive feature ideas
- No harassment, spam, scam links, or doxxing
- No posting OAuth tokens, cookies, API keys or personal data of third parties

## Unacceptable

- Abuse, hate, threats
- Malware / exploit dump in public threads
- Advertising unrelated products without permission
- Impersonating the author or official releases

## Enforcement

Maintainers may edit, lock or delete content and restrict accounts that break this. Report problems via Telegram [@coroner_of_autopsy](https://t.me/coroner_of_autopsy).

## Scope

Applies to GitHub Discussions, Issues, Wiki comments and linked community channels for this project.
