# CoronerChat roadmap

This roadmap expresses direction, not a release commitment.

## Current focus

- Stable reconnect and independent metadata refresh for every platform.
- Multi-provider queued chat TTS (system, cloud, local Piper/Silero/RHVoice + on-demand XTTS/Supertonic) with prefetch and local-first defaults.
- Complete ru/en/ro/de/fi coverage for daily operator flows.
- Verifiable documentation, diagnostics, and portable operation.

## Next

- TikTok LIVE research and a supported connector where platform terms permit it.
- Visual event/action automation with conditions, queues, OBS actions, and reusable presets.
- Public plugin SDK and versioned event contracts.
- Better moderation automation, role policies, and optional local AI assistance.
- Viewer loyalty, rewards, queue, and lightweight interactive modules.

## Later

- Optional encrypted multi-PC synchronization without making cloud use mandatory.
- Mobile/LAN remote control with explicit authentication and scoped permissions.
- Integration gallery and signed community packages.
- Richer XTTS voice cloning UI; optional GPU acceleration hints; more Piper voice packs.

Priorities may change when upstream APIs, authentication rules, or platform availability change.
